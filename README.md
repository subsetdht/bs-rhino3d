# Rhino 3D Learning Repository

This repository collects practical notes, tutorials, exercises, and reference material developed while learning Rhino 3D.

Start at the [knowledge base index](docs/index.md).

## Structure

- `docs/` — organized concepts and reference notes
- `tutorials/` — guided, step-by-step workflows
- `exercises/` — practice tasks and worked solutions

Material should favor clear explanations, repeatable steps, useful screenshots or diagrams, and connections between related Rhino concepts.

## Learning approach

Each topic will move from fundamentals to applied workflows:

1. Explain the underlying concept and vocabulary.
2. Demonstrate it with a small, repeatable exercise.
3. Record common mistakes and recovery techniques.
4. Connect the lesson to related tools and modeling practices.

## How knowledge gets captured

Answering a question is only half the work — the answer must end up in the repository so someone else
can learn from it.

- `.github/copilot-instructions.md` tells Copilot to capture every learning automatically, and where
  it belongs.
- `.github/agents/doc-scribe.md` is the agent that writes and integrates the material.
- `.github/prompts/capture-learning.prompt.md` triggers a capture pass on demand.
- `.github/templates/` holds the doc, tutorial, and exercise formats to follow.
